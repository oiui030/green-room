# 초록방 (green-room)

혼자 사는 방의 식물을 찾고, 돌보고, 이상할 때 살리는 모바일 웹앱.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # 테스트
npm run build    # 배포용 빌드 (dist/)
```

휴대폰 폭(390px 안팎)에 맞춘 화면이다. 데스크톱에서는 가운데 480px 폭으로 보인다.
데이터는 브라우저의 localStorage에만 저장된다. 서버와 계정이 없다.

## 브랜치 규칙

- `develop`: 모든 작업이 먼저 들어오는 곳. 여기서 `npm test`와 `npm run build`를 통과시킨다.
- `main`: develop에서 테스트를 통과하고 기능이 완결된 것만 병합한다. 반쯤 된 기능은 develop에 남긴다.
- main에 직접 커밋하지 않는다. 병합은 `git merge --no-ff develop`로 해서 어떤 묶음이 올라갔는지 남긴다.

## 들어 있는 기능 (v0.1.0)

| 화면 | 하는 일 |
|---|---|
| 인트로, 소개, 온보딩 | 방의 햇빛과 돌봄 습관을 묻고 저장한다 |
| 내 방 | 오늘 가장 급한 할 일 하나, 내 식물 목록 |
| 돌봄 달력 | 이번 주 표시, 오늘 할 일, 2주 안에 올 일 |
| 도감 | 8종. 방과 습관에 맞춰 순서를 매기고 필터한다 |
| 식물 등록 | 종을 고르고 마지막 물 준 날을 답하면 일정이 생긴다 |
| 식물 상세 | 다음 물, 다음 잎 닦기, 키우는 법, 헤어지기 |
| 개구리 도우미 | 어느 탭에서든 열린다. 증상을 고르면 구조 작전이 만들어진다 |
| 구조 작전 | 단계 체크, 물 금지 기간 동안 물 주기 일정 멈춤 |
| 기록 | 등록, 물, 잎 닦기, 구조 작전이 날짜별로 쌓인다 |
| 도움 요청 | 서울시 반려식물 클리닉 예약 페이지로 연결 |

구조 작전은 고른 증상에 따른 규칙 기반 안내다. 사진 진단이 아니다.

## 구조

```
src/lib/dates.js      날짜 계산 (YYYY-MM-DD 문자열)
src/lib/catalog.js    식물 도감 데이터와 궁합 계산
src/lib/rescue.js     증상별 응급처치 안내
src/lib/schedule.js   돌봄 일정 계산
src/lib/store.jsx     상태, localStorage 저장
src/components/       아이콘, 화면 틀, 개구리 도우미, 할 일 카드
src/screens/          화면
tests/                로직 테스트, 화면 흐름 테스트
docs/                 테스트 기록, 다음 할 일
```
