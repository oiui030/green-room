21개. develop에서 전부 통과한 뒤 main에 병합했다.

- `tests/logic.test.js` (13개): 날짜 계산, 주간 표시, 도감 데이터 검증, 궁합 계산, 돌봄 일정, 물 금지 기간, 식물 삭제.
- `tests/flow.test.jsx` (8개): 첫 실행부터 식물 등록과 물 주기 완료까지, 온보딩 전 접근 차단, 다음 방문 때 복원, 달력과 기록, 도감 순서와 필터, 개구리 도우미와 구조 작전, 삭제 확인.

## 실제 브라우저 확인 (수동 실행)

빌드한 앱을 Chrome 헤드리스로 390x844와 320x640 크기에서 21개 화면 상태를 돌며 확인했다.
저장소에는 아직 넣지 않았다. (다음 할 일 참고)

확인한 것: 가로 넘침, 44px보다 작은 누르는 영역, 잘린 글자, 폰트 로딩, 콘솔 오류, 실패한 요청.

### 이 과정에서 찾아 고친 것

| 문제 | 조치 |
|---|---|
| 필터 버튼 높이가 40px | 44px로 올림 |
| 개구리 버튼이 식물 상세의 "어딘가 이상해요"와 등록 선택지를 가림 | 그 두 화면에서는 개구리 버튼을 숨김. 식물 상세는 같은 도우미를 여는 버튼이 따로 있음 |
| 목록 마지막 항목이 개구리 버튼 밑에 깔림 | 탭 화면 아래 여백을 늘려 끝까지 스크롤되게 함 |
| favicon 404 | 아이콘 추가 |
| 물 금지 구조 작전 중에도 "지금 물 줬어요"가 눌림 | 버튼을 숨기고 저장 단계에서도 막음. 테스트 추가 |
| 식물 상세 아래 버튼 글자가 두 줄로 꺾임 | 버튼 여백과 글자 크기 조정 |
| 구조 중인 식물에 "어딘가 이상해요"가 다시 나옴 | "구조 작전 이어가기"로 바꿈 |

## 디자인 교체 (v18 테마) 확인

회색 배경, 흰 카드, 짙은 초록, 라임 강조로 화면 전체를 바꾼 뒤 다시 확인했다.

- 자동 테스트 21개 통과. 화면 문구와 역할은 그대로 두어 테스트를 고치지 않았다.
- 빌드한 앱을 Chrome 390px, 320px에서 18개 화면 상태로 돌렸다. 누르는 요소 44px 미만, 12px 미만 글자, 가로 스크롤, 콘솔 오류 모두 없음.
- 돌리면서 고친 것: 온보딩과 도감 상세의 버튼이 글자 폭만큼만 그려지던 것, 식물 없는 메인에서 안내 문구가 개구리와 겹치던 것, 320px에서 제목 마지막 글자만 다음 줄로 떨어지던 것.
- 바뀐 동작: 메인의 오늘 할 일이 맨 위 카드 안으로 들어갔다. 메인에 "어딘가 이상해요?" 버튼이 생겨 개구리 도우미를 연다. 기록 화면의 식물 타일은 뺐다.

## 식물 실루엣 8종과 온보딩 구조 변경 확인

- 도감 8종의 선 아이콘을 채워진 실루엣으로 바꿨다. 잎맥 같은 안쪽 선은 블롭 배경색으로 그려 틈처럼 보인다.
- 온보딩을 질문 하나에 화면 하나로 나눴다 (햇빛, 돌봄 습관, 식물 유무). 뒤로 가도 고른 답이 남는지 테스트에 추가했다.
- 자동 테스트 21개 통과. Chrome 390px, 320px에서 20개 화면 상태 확인, 문제 없음.
- 돌리면서 고친 것: 도감 카드에서 "열흘에 한 번"이 글자 중간에 줄바꿈되던 것.

## 개구리 버튼이 뒤 화면과 겹쳐 보이던 문제

- 원인: 버튼이 화면에 고정돼 있어 스크롤 중인 타일이나 카드가 그 아래로 지나가고, 라임 테두리가 초록 블롭과 붙어 보였다.
- 고침: 버튼 둘레에 배경색 띠를 둘러 떼어 놓고, 탭 바로 위에서 내용이 배경색으로 옅어지게 했다.
- 끝까지 스크롤하면 마지막 줄은 버튼 위에서 멈춘다 (아래 여백은 그대로).
- 자동 테스트 21개 통과, Chrome 390px과 320px에서 다시 확인.
