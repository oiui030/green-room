## 실제 브라우저 확인 (수동 실행)

빌드한 앱을 Chrome 헤드리스로 390x844와 320x640 크기에서 21개 화면 상태를 돌며 확인했다.
저장소에는 아직 넣지 않았다. (다음 할 일 참고)

확인한 것: 가로 넘침, 44px보다 작은 누르는 영역, 잘린 글자, 폰트 로딩, 콘솔 오류, 실패한 요청.

### 이 과정에서 찾아 고친 것

| 문제 | 조치 |
|---|---|
| 필터 버튼 높이가 40px | 44px로 올림 |
| 개구리 버튼이 식물 상세의 "어딘가 이상해요"와 등록 선택지를 가림 | 그 두 화면에서는 개구리 버튼을 숨김. 식물 상세는 같은 도우미를 여는 버튼이 따로 있음 |
| 목록 마지막 항목이 개구리 버튼 밑에 깔림 | 탭 화면 아래 여백을 늘려 끝까지 스크롤되게 함 |
| favicon 404 | 아이콘 추가 |
| 물 금지 구조 작전 중에도 "지금 물 줬어요"가 눌림 | 버튼을 숨기고 저장 단계에서도 막음. 테스트 추가 |
| 식물 상세 아래 버튼 글자가 두 줄로 꺾임 | 버튼 여백과 글자 크기 조정 |
| 구조 중인 식물에 "어딘가 이상해요"가 다시 나옴 | "구조 작전 이어가기"로 바꿈 |

## 디자인 교체 (v18 테마) 확인

회색 배경, 흰 카드, 짙은 초록, 라임 강조로 화면 전체를 바꾼 뒤 다시 확인했다.

- 자동 테스트 21개 통과. 화면 문구와 역할은 그대로 두어 테스트를 고치지 않았다.
- 빌드한 앱을 Chrome 390px, 320px에서 18개 화면 상태로 돌렸다. 누르는 요소 44px 미만, 12px 미만 글자, 가로 스크롤, 콘솔 오류 모두 없음.
- 돌리면서 고친 것: 온보딩과 도감 상세의 버튼이 글자 폭만큼만 그려지던 것, 식물 없는 메인에서 안내 문구가 개구리와 겹치던 것, 320px에서 제목 마지막 글자만 다음 줄로 떨어지던 것.
- 바뀐 동작: 메인의 오늘 할 일이 맨 위 카드 안으로 들어갔다. 메인에 "어딘가 이상해요?" 버튼이 생겨 개구리 도우미를 연다. 기록 화면의 식물 타일은 뺐다.

## 식물 실루엣 8종과 온보딩 구조 변경 확인

- 도감 8종의 선 아이콘을 채워진 실루엣으로 바꿨다. 잎맥 같은 안쪽 선은 블롭 배경색으로 그려 틈처럼 보인다.
- 온보딩을 질문 하나에 화면 하나로 나눴다 (햇빛, 돌봄 습관, 식물 유무). 뒤로 가도 고른 답이 남는지 테스트에 추가했다.
- 자동 테스트 21개 통과. Chrome 390px, 320px에서 20개 화면 상태 확인, 문제 없음.
- 돌리면서 고친 것: 도감 카드에서 "열흘에 한 번"이 글자 중간에 줄바꿈되던 것.

## 개구리 버튼이 뒤 화면과 겹쳐 보이던 문제

- 원인: 버튼이 화면에 고정돼 있어 스크롤 중인 타일이나 카드가 그 아래로 지나가고, 라임 테두리가 초록 블롭과 붙어 보였다.
- 고침: 버튼 둘레에 배경색 띠를 둘러 뒤의 블롭과 떼어 놓았다. 탭 위에서 내용을 옅게 지우는 처리는 넣었다가 뺐다 (화면이 뿌옇게 보여서).
- 하단 탭도 함께 바꿨다. 짙은 초록 바에 라임 블롭이던 것을 흰 바로 바꾸고, 탭 이름을 모두 보이게 했다. 선택된 탭은 아이콘에 짙은 초록 알약과 라임 아이콘.
- 끝까지 스크롤하면 마지막 줄은 버튼 위에서 멈춘다 (아래 여백은 그대로).
- 자동 테스트 21개 통과, Chrome 390px과 320px에서 다시 확인.

## 직접 써보며 찾은 것 (0.2.0)

인트로부터 등록, 물 주기, 구조 작전, 기록까지 사용자처럼 한 바퀴 돌고 고친 것.

| 써보니 | 고친 것 |
|---|---|
| "줬어요"를 잘못 눌러도 되돌릴 수 없다 | 누르면 아래에 확인 문구와 되돌리기가 6초 동안 뜬다 |
| 구조 작전 중인데 메인은 "오늘 할 일 없음, 구경만 하고 가도 돼요"라고 한다 | 메인 카드가 구조 작전 진행 상황과 이어가기 버튼을 보여준다. 돌봄 달력에도 진행 중인 작전이 모두 나온다 |
| 식물 없는 메인이 카드 하나뿐이라 다음에 뭘 할지 모르겠다 | 내 방에 맞는 식물 3종과 "이미 키우는 식물이 있어요"를 바로 보여준다 |
| 온보딩에서 고른 방 조건을 나중에 볼 수도 바꿀 수도 없다 | 도감 위에 지금 기준을 적고 바꾸기를 뒀다. 다시 들어가면 저장된 답에서 시작한다 |
| 도감 필터가 두 줄로 넘어간다 | 한 줄로 두고 옆으로 민다 |
| 소개 화면 말풍선이 글자 중간에서 줄바꿈된다 | 단어 단위로 줄바꿈 |
| 홈 화면에 추가하면 아이콘이 없다 | 앱 아이콘과 홈 화면용 설정 추가 |

자동 테스트는 24개로 늘었다 (되돌리기, 구조 작전 중 메인, 빈 메인 추천과 방 조건 바꾸기). Chrome 390px, 320px에서 20개 화면 상태 다시 확인, 문제 없음.

테스트용 링크는 `npm run build:preview`로 만든 빌드를 쓴다. 주소에 화면 경로를 담지 못하는 곳에서도 돌도록 화면 이동을 메모리에서 처리한다.

## 개구리 도우미를 대화 형태로

- 개구리가 묻고, 사용자가 제안된 답을 누르거나 직접 적는다. 답은 모두 정해진 대본이고, 적은 글은 몇 가지 낱말로만 알아본다 (언어 모델 없음). 못 알아보면 그렇다고 말하고 고를 것을 다시 보여준다.
- 할 수 있는 것: 증상 고르기와 구조 작전 시작(시작 전에 한 번 확인), 물 줄 날 알려주기, 내 방에 맞는 식물 추천, 사람 도움으로 보내기.
- 대화의 박자: 개구리가 답하기 전에 점 세 개가 0.5초에서 1.2초 동안 움직이고(답이 길수록 조금 더), 말풍선이 떠오른 뒤 고를 답이 따라 나온다. 쓰는 동안에는 보내기가 잠긴다. 움직임 줄이기 설정이면 애니메이션 없이 짧게 기다린다.
- 자동 테스트 29개 통과 (대화 3개, 낱말 알아보기와 대기 시간 2개 추가). 테스트에서는 대기 없이 돈다.
- 이전 기록: 자동 테스트 27개 통과 (대화 3개 추가). Chrome 390px과 320px에서 대화 8단계 확인: 44px 미만 버튼 없음, 새 답이 항상 보이는 위치로 스크롤됨.
